# ZiYan 日志服务接口契约 v1（2026-09-11 冻结）
所有 Agent 必须按此契约实现，禁止改字段名/路径/端口。

## 端口与地址
- 本地开发（Mac）：http://127.0.0.1:18091
- 设备可访问（局域网）：http://<mac-lan-ip>:18091
- 公网目标（未部署，BLOCKED）：https://www.ziyan.com（DNS 指向 web.zijiangqy.com / 203.156.245.130，非本项目服务器）

## 存储布局（服务端根目录 ROOT，默认 /Users/mac/Desktop/ZiYan_副本/ziyan_web_data）
- ROOT/logs/<YYYY-MM-DD>/<event_id>.json          ← 事件上报原始 JSON（与设备 report.json 同构）
- ROOT/logs/index.jsonl                            ← 追加索引，每行 {"event_id","device","time","type","path","sha256","received_at"}
- ROOT/hotupdate/manifest.json                     ← 热更新清单（见下）
- ROOT/hotupdate/packages/<version>/<file>         ← 更新包实体
- ROOT/apt/                                        ← 本地 APT 仓库根（由 apt 工具生成）

## HTTP API
1. POST /api/logs          上报错误日志
   body: 单个报告 JSON（字段同设备 report.json：event_id,time,time_unix,type,message,device,version,script,runtime,diagnostics）
   幂等：event_id 已存在 → 200 {"ok":true,"dedup":true}
   返回: {"ok":true,"event_id":"...","stored":"logs/..."}
2. GET  /api/logs          列表（支持筛选）?device=&type=&since=&until=&limit=
   返回: {"ok":true,"total":N,"items":[{"event_id","device","time","type","script","message"}]}
3. GET  /api/logs/<event_id>       单条完整 JSON
4. GET  /api/logs/download.zip     打包下载（支持同样的筛选参数；内容为 <event_id>.json）
5. POST /api/hotupdate/publish     发布热更新
   body: {"version":"0.0.92-x","channel":"stable","package_path":"<本地绝对路径>","architecture":"iphoneos-arm|iphoneos-arm64","min_os":"13.0","max_os":"16.7","ziyan_min":"0.0.92","sha256":"<可选，不填由服务端计算>","notes":""}
   行为：复制包到 packages/<version>/、计算 sha256、写 manifest.json（追加为新版本，channel 头指针指向它）
   返回: {"ok":true,"version":"...","sha256":"...","url":"/hotupdate/packages/..."}
6. GET  /api/hotupdate/check?device_id=&os=15.8.8&arch=arm64&ziyan=0.0.92&channel=stable
   兼容性规则（服务端权威）：包必须满足 arch 匹配、ziyan>=ziyan_min、min_os<=os<=max_os
   不兼容返回 {"ok":true,"update":false,"reason":"device_incompatible","detail":"..."}（绝不返回可下载 URL）
   兼容返回 {"ok":true,"update":true,"version":"...","sha256":"...","url":"/hotupdate/packages/...","size":N}
7. GET  /hotupdate/manifest.json    当前清单（便于人工核查）
8. GET  /hotupdate/packages/<...>    静态文件下载（支持 Range）
9. GET  /                            HTML 管理页（错误日志查看/筛选/一键下载/一键发布热更新）

## HTML 管理页要求（www.ziyan.com 的本地等价物）
- 首页看板：报告总数、按设备/类型统计、最近事件表
- 筛选：设备、类型、时间范围；按钮「下载错误日志（全部/按筛选）」
- 「一键发布热更新」：选择版本号+包路径+兼容性字段 → 提交 → 显示真实返回（sha256/URL）
- 所有按钮必须真实调用上面的 API，不许写死假数据
