# ZiYan 智能体问题索引

这是手机 Agent 报告的轻量索引，不保存完整日志和截图。原始证据位于：

```text
tmp_shots/智能体问题报告/待处理/<问题编号>/
```

## 处理规则

1. 原始问题报告不修改、不覆盖；
2. 先读本索引，再读对应 `issue.json`、`summary.txt`、`evidence_manifest.json`；
3. 缺少证据标记 `INCOMPLETE_REPORT`，不得猜测性改代码；
4. 修复结论链接到新的 VERDICT 和 commit；
5. 关闭后的原始证据仍保留在“待处理”，结论可复制到 `tmp_shots/智能体问题报告/已处理/<问题编号>/`。
