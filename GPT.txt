====================
项目名称：
ZiYan 子砚自动化引擎


项目目标：
打造类似触动精灵的下一代 iOS 自动化开发平台。

支持：
Lua自动化脚本
图色识别
OCR识别
触控控制
游戏状态机
AI脚本生成
真机自动化测试

硬规则：
- 禁止拷贝 TouchSprite / XXTouch 源码与私有 API
- 禁止固定物理像素点击；管道 Device→Screen→Coordinate→Vision→OCR→Touch→Verify→StateMachine
- 正确点击：Touch.atRatio / atDesign / atHit（Helper.tap = 设计坐标）
- 验证 App：仅作手工/脚本测试样本，禁止写死进 ZiYanDefense.plist Filter
  （Defense 对 UIKit 第三方 App 通用；样本常见于 DEVICE_RULES / 测试脚本）
- 无真机测试结果不得标记业务成功
- 【7.6.1-A】子砚功能验证结论仅允许在第二类设备（.53/.166）产生；.149/.171 仅为 TS 观察
- SECURITY_AI：防游戏=App 内 Defense（Shadow essential）；爱思=原生 AFC；说明见
  子砚工程防御/项目防御说明.txt
====================

当前架构：

objc/     — 底层：App、ZiYanVol、AppTouch、ScriptRunner、Engine
lua/      — API 真相源：modules/* + ziyan_engine/*

layout/   — 装机路径镜像
tools/    — 文档生成、OCR、冒烟工具

Script/   — 用户脚本 SDK
GPT.txt / GPT_PROJECT_STATE.txt / DEVICE_RULES.md
