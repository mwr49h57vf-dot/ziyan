子砚取点抓色器 v1.7.4
====================
唯一主程序：ZiYanColorPicker.py
色串唯一源：formats.py
抄触动 TSColorPicker 1.7.10 窗口角色：
  主窗 = 子砚取点抓色器(ZiYanColorPicker) - [图] + 文件/编辑/窗口/帮助 + 图标工具栏 + 图
  浮窗 = 取色面板（不含手机 IP）
生成色参只服务 Desktop ios7.lua / ios8p.lua（本抓色器产出）
禁止用触动精灵色参替换或写入自测样例。

启动
  Mac:    ./run.sh
          或 python3 ZiYanColorPicker.py
  Windows: 双击 启动取色器.bat

设备截屏（不需要 SSH）
  1. 手机子砚 framecap 监听 50005（占用则 50015）
  2. 主窗「文件 → 连接设备」填 IP → 探测 / 截屏
  3. 测试找色：取色面板「<-测试」走 POST /findtest（PC 不弹结果窗）

协议
  GET  /status
  GET  /snapshot?orient=
  POST /findtest

自测（只对照 Desktop，不改色参）
  python3 ZiYanColorPicker.py --test
  python3 ZiYanColorPicker.py --smoke

兼容入口
  ziyan_colorpicker.py → 转调 ZiYanColorPicker.py（无第二套 UI）
