子砚取点抓色器 v1.7.5
==============

唯一主程序：ZiYanColorPicker.py（色串：formats.py）
抄触动精灵取点抓色器(TSColorPicker) 1.7.10：
  主窗放图和工具栏，取色面板是浮窗。
Windows 用本目录打出的 ZiYan.exe；旧包 v175/v174/v134 已废弃。
发给别人只发 ZiYan.zip（只有 ZiYan.exe）。源码只留在本目录自己改。

设备截屏（不需要 SSH）
  1. 手机安装子砚（framecap 监听 50005，占用则 50015）
  2. 主窗「文件 → 连接设备」填 IP → 探测 / 截屏
  3. 「<-测试」→ POST /findtest（与机上 ColorMatch 同核；PC 不弹窗）

协议：
  GET  /status     → zy1 文本 + JSON
  GET  /snapshot   → PNG
  POST /findtest   → 同核找色 JSON

启动：
  Mac:     cd tools/ziyan_colorpicker && ./run.sh
  Windows: 双击 启动取色器.bat

自测：python3 ZiYanColorPicker.py --test
  （只 roundtrip Desktop ios7/ios8p，禁止触动色参）
