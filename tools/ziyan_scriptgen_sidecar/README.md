# 侧车脚本验收

生成输出使用与原生客户端相同的依赖契约。普通注释、长注释和说明字符串不会触发依赖拒绝。禁止库引用、动态加载、无法静态确定的加载参数会被拒绝。

业务检查要求四个阶段函数声明和 runApp 调用。随后必须通过真实 Lua 的语法检查。检查只编译文本，禁止执行候选脚本和 LUA_INIT。该检查不构成 Lua 沙箱，也不证明业务已在设备上完成。

启动前通过 ZIYAN_SCRIPTGEN_LUA 指定可信的主机 Lua 5.3 可执行文件绝对路径。未设置时只查找 PATH 中的 lua5.3 或 lua。缺少工具、输入超过 1 MiB、编译失败或超过 5 秒时，接口返回 ok=false 和明确错误，from_sidecar=false。

原生客户端独立使用包内 lua5.3 再检查一次，期限为 3 秒。失败保留既有本地模板回退，记录失败原因，不标为侧车成功。

本地验证入口：tools/run_repair_regressions.py --lua <已安装的 Lua 5.3 可执行文件>。

完整 iOS 路由仍需在具有 Theos 和 iOS SDK 的机器构建后验收。
