====================
标记：LOCK_ICON_HIDE

稳定范围（手签2 语义，双机同方案 · **8-122 hide-once 性能修订**）：
1. 打开 ZiYan App → **仅边沿隐藏一次**越狱图标（Cydia/Sileo/Filza/NewTerm/Zebra/Dopamine/TrollStore 等）
2. 保留 com.ziyan.ziyan（ZiYan.app）图标可见
3. Home 最小化 → 保持隐藏（仅认 `.ziyan_app_session` 粘性，含 Media 双写；**禁止回 SB 持续 ps/desk_hide/uicache**）
4. 「关闭程序」/ App willTerminate / 冷启·断电无 session → 恢复桌面图标
5. 主路径：ziyan_fscloakd 改名 `*.ziyan_desk_hidden` + uicache；辅路径：SB IconShield 软隐藏
6. 禁止 rename/kill afc2d、禁止杀 lockdownd（爱思稳态）

禁止改动：
- 不得再用 `.ziyan_script_session` / `.ziyan_project_active` 冒充 App 存活决定 desk_HIDE/SHOW
- 不得恢复「每秒 hide_req / 每拍进主队列 hideJailbreakIconsIfNeeded」（会与找色抢 SB）
- 不得缩短「关程序才 restore」语义导致 Home 后误 desk_SHOW
- ZiYanIconShield / ZiYanBootRecovery 图标分支 / ziyan_fscloakd.sh **hide-once 边沿**语义
- 不得为「对齐 TSDaemon」擅自扩宽隐藏触发条件（须书面申请）

实现要点（8-122 · 用户授权 LOCK_ICON_HIDE 性能优化）：
- App：`ceshiAppDelegate` 冷启写 session + **一次** hide_req；心跳**只**续 session/heartbeat（禁刷 hide_req）
- SB：IconShield **5s 边沿**；已隐藏则不进主队列；CloseApp → restore_req
- Daemon：fscloakd **v8122 hide_once** — 仅 session 0→1 时 desk_hide；已隐藏静默；僵尸 session 约 90s 慢检
