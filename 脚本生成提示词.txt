# 子砚 · 脚本生成提示词框架（唯一执行约定）

> **本文件 = 唯一提示词真源**（合并进阶侧车 + 工程对照 + **冲突禁区** + **备份/回归闭环**）。  
> 工程根：`/Users/mac/Desktop/ZiYan_副本`  
> 用途：实现/验收「我的脚本」底栏 —— **录制脚本（音量+）**、**自动脱壳（含自动分析）**。  
> 硬性：脱壳链路必须走项目内三大模型（Mac 侧车）；录制链路为真机触控事件→Lua，禁止 TSLib。  
> 硬性：**增功能前备份；自测失败必须自动读取回归文档并按文档重做，禁止盲改硬锁区。**  
> 矩阵：越狱 iPhone 7 / 7P / 8 / 8P · iOS 13～16.7.16（rootful + rootless；后续扩展待告知）。  
> 包锚点参考：`control` 现版（实现时以真机 `dpkg` 为准）。

## 8. 流水线 · 录制脚本（用户验收真源 · R8.4.12）

> **产品入口**：底栏左钮「录制脚本」→ `recordScriptTapped` → 武装 → **音量「+」** 起停。  
> **学触动公开教程**：音量+ 录制/停止；音量− 仍为运行菜单（本工程硬锁，不照搬触动菜单）。  
> **禁止**：改 `LOCK_VOLUME_OVERLAY` 的 PresentMenu/Pause/Continue/Stop；禁止 TSLib。

### 8.0 用户可见步骤

```
点击「录制脚本」
    ↓
① 选择指定 App（AppSelector）
    ↓
② 武装录制：写 .ziyan_rec_armed；开游；Toast「按音量+开始」
    ↓
③ 按音量「+」→ 开始录制（.ziyan_recording）；Toast「开始录制」
    ↓
④ 用户在游戏内点击 → AppTouch 钩 sendEvent → 逻辑坐标写入 .ziyan_rec_events.jsonl
    ↓
⑤ 再按音量「+」→ 停止 → 生成 Media/ZiYan/rec_yyyyMMdd_HHmmss.lua
    ↓
⑥ 列表刷新 / Toast「录制已保存」→ 可用顶栏播放或音量−菜单运行
```

### 8.1 状态文件

| 文件 | 含义 |
|------|------|
| `.ziyan_rec_armed` | 已选 App，等待音量+ 开始 |
| `.ziyan_recording` | 正在录制（含 bid/started） |
| `.ziyan_rec_events.jsonl` | tap 事件流（逻辑坐标 + gap_ms） |
| `.ziyan_rec_last.json` | 最近产物路径 / taps 数 |

### 8.2 产物契约

```lua
function main()
  init(1)
  tap(x, y)   -- 逻辑坐标；回放走 LOCK_TOUCH_BASE
  mSleep(gap)
  ...
end
main()
```

- 无 `TSLib` / `require("ts")`  
- 坐标经 OrientMap 窗口→逻辑；回放 `tap` 经引擎 HID  
- 控截图：录制本身不跑 find 循环；回放脚本勿空转狂截  

### 8.3 可选 · Agent 自动生成（CLI / 侧车，非底栏主入口）

底栏主入口已改为录制。`ziyan_scriptgen_smoke` / `generateForApp` 的 P→V→K→G→T 仍保留作进阶生成，见历史 §8.2 Fable 封装；**勿与录制按钮抢入口**。

### 8.2（历史）Fable 工作法 · 本地 Agent 封装（R8.4.11 · 不接任何收费 API）

> **只借思路，不借 Anthropic / Claude Fable 云 API。**

## 10. 生成脚本运行时契约

```lua
function main()
  init(1)
  keepScreen(true)
  local deadline = os.time() + 3600
  while os.time() < deadline do
    local x, y = findMultiColorInRegionFuzzy(0xRRGGBB, "…", 90, x1,y1,x2,y2)
    if x ~= -1 then tap(x, y) else -- recover end
    mSleep(500)
  end
  keepScreen(false)  -- 使用后清理（对齐手册）
end
```

色参来源优先级：LiveLearn 自动取色 > 训练库导入 > 运行时 OCR。  
性能看 `.ziyan_sb_find_perf`（`sb_avg_ms`）。作者脚本另名，禁止覆盖。

### 14.5 脚本生成功能专属回归注意

- 与防御模型共享磁盘权重时，**结论文件必须隔离**（§7.3）。
